- 六个模块已正式接入：`bar_architecture`、`bar_counter`、`bar_backbar`、`bar_furniture`、`bar_lighting`、`bar_wear_overlays`。

- 默认游戏使用正式环境；任一模块缺失时事务式清理并整体回退到完整可玩灰盒。
- 导入 GLB 只负责视觉；碰撞、稳定 ID、柜门／抽屉状态、14 盏逻辑灯和双世界共享玩法状态由 Godot 包装层拥有。
- 用户已批准现实暖色与眼镜冷色的最终 Forward+ 灯光候选。24 张 `1920×1080` 生产集成图已人工检查。

### 工具与玩法技术基线

- 阶段 1／2 共九项工具资产已通过各自视觉检查点并正式接入：高球杯、三种量酒器、研钵、研杵、传统滤器、豆铲、冰夹。
- 第一人称移动、双手实体工具、柜体与储物、数据驱动工序、参数化液体、每日洗手、量酒器取水、有限重复补救、评价、日结和 30 天原型循环已实现。
- 权威玩法状态与表现层已经分离；现实／眼镜世界共享唯一状态，眼镜世界提供观察和规划信息而不自动执行操作。
- Schema version 1 状态快照与内存往返已实现；它不是正式磁盘存档产品。
- 正式配方目录包含 9 杯饮品和 26 个成分形态，引用闭合并保留“滴／勺／少量／未注明”等原始量词；冰美式标为 `Partial`，其余 8 杯标为 `CatalogOnly`。
- 冰美式已使用正式稳定 ID `iced_americano`；旧快照 ID `prototype_iced_americano` 会在反序列化时迁移。
- 三种双头量酒器容量为 `10/20`、`15/30`、`25/50 ml`；直接加水按实际载量转移，当前冰美式通过五次 20ml 加水达到 100ml，咖啡豆按两勺各 9g 达到 18g。
